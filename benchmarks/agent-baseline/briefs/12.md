# 12 D3

Source: https://doi.org/10.1109/TVCG.2011.185

## Paper Context

D3 binds data to document elements and uses declarative transformations to produce interactive visualizations. Its core abstraction is a data join that creates enter, update, and exit selections.

## Figure Intent

Show data flowing into a selection/join operation that updates document elements. The figure should express the mapping between data values and visual marks.

## Concepts To Show

- Input data table or array
- Selection
- Data join
- Enter/update/exit sets
- DOM/SVG elements
- Visual marks
- Interaction/update loop

## Relationships

Data is joined to selected document elements. Missing elements enter, existing elements update, and obsolete elements exit. The resulting DOM/SVG elements become visible marks.

## Chinese Labels

Include labels such as `数据绑定`, `选择集`, `进入`, `更新`, `退出`.

## Design Notes

Use a split after the join into enter/update/exit lanes, then recombine into document marks. This conveys D3 better than a plain data-to-chart arrow.

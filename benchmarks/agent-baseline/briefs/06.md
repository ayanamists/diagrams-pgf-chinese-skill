# 06 ResNet

Source: https://openaccess.thecvf.com/content_cvpr_2016/html/He_Deep_Residual_Learning_CVPR_2016_paper.html

## Paper Context

ResNet trains very deep networks by learning residual functions. A residual block passes an input through a stack of layers while also carrying an identity shortcut to an addition node.

## Figure Intent

Show why the shortcut matters. The viewer should see that the block computes a residual transformation and adds it back to the original input.

## Concepts To Show

- Input activation `x`
- Weight layer or convolution
- Activation/nonlinearity
- Second weight layer or convolution
- Identity shortcut
- Addition node
- Output activation

## Relationships

The main path transforms `x` through layers. A parallel shortcut bypasses those layers. Both paths meet at an addition node, then produce the block output.

## Chinese Labels

Include labels such as `残差块`, `恒等捷径`, `卷积层`, `相加`.

## Design Notes

Use a strong parallel route for the skip connection. The shortcut should be visually distinct from the main computation path and should attach unambiguously at the addition node.

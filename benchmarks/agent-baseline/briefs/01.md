# 01 egg

Source: https://arxiv.org/abs/2004.03082

## Paper Context

`egg` is a library for equality saturation. The core idea is to represent many equivalent expressions compactly in an e-graph, repeatedly apply rewrite rules, and then extract a good expression according to a cost model.

## Figure Intent

Show a small equality-saturation workflow, not a generic three-box pipeline. The viewer should understand that rewrites expand the e-graph, analysis maintains facts, and extraction chooses one final expression.

## Concepts To Show

- Input expression
- Rewrite rules
- E-graph containing e-classes/e-nodes
- Saturation loop
- Analysis or rebuild step
- Cost-based extraction
- Output optimized expression

## Relationships

Input expression initializes the e-graph. Rewrite rules and analysis feed a repeated saturation loop. The saturated e-graph feeds extraction. Extraction produces the selected optimized expression.

## Chinese Labels

Include labels such as `等式饱和`, `重写规则`, `等价图`, `代价提取`.

## Design Notes

Use a loop around the e-graph area. Put the final extraction path clearly to the right so the iterative part and one-way output path are visually distinct.

# 09 AlphaFold

Source: https://www.nature.com/articles/s41586-021-03819-2

## Paper Context

AlphaFold predicts protein structure from sequence information by combining multiple sequence alignments, template information, pair representations, iterative neural processing, and a structure module that outputs 3D coordinates.

## Figure Intent

Show information moving from sequence evidence into representation learning and then into 3D structure prediction. The figure should distinguish sequence/MSA information from pair/geometric representation.

## Concepts To Show

- Amino-acid sequence
- MSA features
- Template features
- Pair representation
- Evoformer or iterative trunk
- Structure module
- Predicted 3D coordinates/confidence

## Relationships

Sequence, MSA, and template features initialize representations. Iterative processing updates sequence and pair representations. The structure module converts representations into predicted coordinates.

## Chinese Labels

Include labels such as `序列`, `多序列比对`, `结构模块`, `三维坐标`.

## Design Notes

Use two input streams merging into a central representation block, then a final geometry output. Do not draw a generic neural network stack with no biological inputs.

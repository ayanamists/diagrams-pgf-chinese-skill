# 17 WASH

Source: https://pmc.ncbi.nlm.nih.gov/articles/PMC8207965/

## Paper Context

This work discusses how implementation science can support water, sanitation, and hygiene research and practice. It connects interventions, context, implementation strategies, implementation outcomes, and public-health impact.

## Figure Intent

Show implementation as a staged system, not just intervention to outcome. Context and barriers/facilitators should visibly influence implementation.

## Concepts To Show

- WASH intervention
- Context
- Barriers and facilitators
- Implementation strategy
- Implementation outcomes
- Service or behavior outcomes
- Population health impact

## Relationships

Intervention and context inform implementation strategy. Strategy affects implementation outcomes. Those outcomes influence service/behavior outcomes and then health impact. Feedback can revise strategy.

## Chinese Labels

Include labels such as `实施策略`, `情境`, `障碍`, `促进因素`, `健康影响`.

## Design Notes

Use a main pipeline with a context band or side influence. Do not hide context in a tiny annotation; it is central to implementation science.

# 10 MapReduce

Source: https://research.google/pubs/mapreduce-simplified-data-processing-on-large-clusters/

## Paper Context

MapReduce is a programming model and runtime for large-scale distributed data processing. Users provide map and reduce functions; the runtime splits input, schedules workers, shuffles intermediate key/value pairs, and writes output.

## Figure Intent

Show distributed execution with a master coordinating many map and reduce workers. The shuffle between map and reduce phases should be prominent.

## Concepts To Show

- Input splits
- Map workers
- Intermediate key/value partitions
- Shuffle/sort
- Reduce workers
- Output files
- Master or scheduler

## Relationships

Input splits are assigned to map workers. Map outputs are partitioned and shuffled to reduce workers. Reduce workers write final output. A master coordinates task assignment and failure recovery.

## Chinese Labels

Include labels such as `输入分片`, `映射`, `洗牌`, `归约`, `调度`.

## Design Notes

Use fan-out from input to maps, many-to-many shuffle, and fan-in/out to reduces. A single straight pipeline hides the distributed nature.

# 04 LLVM

Source: https://llvm.org/pubs/2004-01-30-CGO-LLVM.html

## Paper Context

LLVM presents a reusable compiler framework centered on a typed intermediate representation. Front ends translate languages into LLVM IR, common analyses and transformations optimize IR, and back ends lower IR to different targets.

## Figure Intent

Show the separation between multiple front ends, a shared IR optimization core, and multiple target back ends. The key message is reuse through a common IR.

## Concepts To Show

- C/C++ or source-language front end
- Another front end or source language
- LLVM IR
- Analysis and optimization passes
- Code generator
- Multiple target architectures

## Relationships

Several front ends converge into LLVM IR. Analysis/optimization operates on the shared IR. Several back ends diverge from the IR toward target code.

## Chinese Labels

Include labels such as `前端`, `中间表示`, `优化`, `后端`.

## Design Notes

Use an hourglass shape: many inputs, narrow shared IR/optimizer center, many outputs. This better expresses the framework than a single straight pipeline.

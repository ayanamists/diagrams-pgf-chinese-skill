# 03 MLIR

Source: https://arxiv.org/abs/2002.11054

## Paper Context

MLIR is a compiler infrastructure built around extensible intermediate representations called dialects. It supports progressive lowering from high-level domain abstractions to lower-level representations while preserving analyzable structure.

## Figure Intent

Show compiler lowering as a stack of dialects and passes, with transformations moving between levels. The viewer should see why MLIR is not one monolithic IR.

## Concepts To Show

- Source or domain operation
- High-level dialect
- Tensor/Linalg-like layer
- Affine or loop layer
- LLVM-like low-level layer
- Pass manager or transformations
- Target code

## Relationships

Operations live inside dialect layers. Passes rewrite or lower between dialects. The flow descends from high-level program structure toward target-specific code.

## Chinese Labels

Include labels such as `方言`, `逐层降低`, `优化通道`, `目标代码`.

## Design Notes

A vertical stack is appropriate. Add side arrows for optimization passes so the figure does not become only a list of rectangles.
